# IMR Instrucon

Sistema web estático para preencher e imprimir o Instrumento de Medição de Resultado (IMR) da Instrucon.

## Funcionalidades

- Preenchimento dos dados de contrato, requisição, unidade, fiscal e portaria.
- Registro da pontuação de cada ocorrência.
- Cálculo automático do IMR total.
- Geração de uma prévia A4 pronta para impressão, com a formatação visual do modelo.

## Como usar

1. Abra `index.html` no navegador.
2. Preencha os campos do formulário e informe os pontos das ocorrências.
3. Selecione **Gerar documento**.
4. Revise a prévia e use **Imprimir**.

## Tecnologias

HTML, CSS e JavaScript puro. Não utiliza banco de dados nem dependências externas.
